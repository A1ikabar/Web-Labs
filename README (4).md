# Lab Project API

## Описание проекта

Данный проект представляет собой backend-приложение с REST API, разработанное в рамках лабораторных работ.  
В приложении реализована система аутентификации пользователей (JWT + Cookies), а также CRUD-операции для работы с сущностью "Works".

В рамках лабораторной работы №4 была добавлена автоматическая документация API с использованием OpenAPI (Swagger).  
Документация генерируется на основе кода приложения (Code-First подход).

## Функциональность

- Регистрация и авторизация пользователей
- Обновление токенов (refresh)
- Получение информации о текущем пользователе (/whoami)
- Выход из системы (в том числе со всех устройств)
- CRUD операции для сущности "Works"
- Пагинация списка работ
- Soft delete (логическое удаление записей)

## Технологии

- Python 3
- Django
- Django REST Framework
- drf-spectacular (OpenAPI / Swagger)
- PostgreSQL
- Docker / Docker Compose

## API документация

Документация API доступна по адресу:

http://localhost:8000/api/docs/

Документация генерируется автоматически на основе кода приложения.

## Переменные окружения

DB_NAME=postgres

## Особенности реализации

Документация API реализована с использованием Code-First подхода
Все эндпоинты аннотированы с помощью @extend_schema
Добавлены примеры запросов и ответов (examples)
Описаны возможные коды ошибок (400, 401, 403, 404)
Настроена схема безопасности (JWT / Cookies)
Защищённые эндпоинты требуют авторизации (отмечены в Swagger)
